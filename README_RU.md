# Mi Monitor Light Tray

> [中文](README.md) · [English](README_EN.md)

Программа для Windows, которая управляет лампами Xiaomi / Yeelight из системного трея: включение, яркость, температура света и горячие клавиши. Команды отправляются лампам по локальной сети через [python-miio](https://github.com/rytilahti/python-miio). Можно добавить несколько устройств с отдельными настройками и правилами включения и выключения.

## Установка и язык

1. Скачайте `MiMonitorLightTray.exe` со страницы [Releases](https://github.com/awakaze/MiMonitorLightTray/releases) и запустите. Python устанавливать не нужно.
2. Найдите значок программы рядом с часами. Windows может скрыть его под стрелкой вверх.
3. Нажмите значок правой кнопкой → **Language / Язык / 语言 → Русский**. Выбор применяется сразу и сохраняется.

Доступны русский, английский и китайский языки. По умолчанию выбрано **Как в Windows / System default**: программа использует язык интерфейса Windows, а для неподдерживаемого языка — английский.

Язык также можно выбрать в **Настройках → Общие настройки**. Изменение показывается сразу; **Сохранить** запоминает выбор, **Отмена** возвращает прежний язык.

## Добавление ламп

1. Добавьте лампу в Xiaomi Home на телефоне. Регион приложения должен соответствовать устройству.
2. Подключите компьютер и лампу к одной локальной сети. Компьютер может быть подключён кабелем.
3. В программе откройте **Настройки → Импорт из облака**, отсканируйте QR-код через Xiaomi Home и выберите устройства.
4. Подтвердите импорт и сохраните настройки.

Для ручного добавления нажмите **+ Добавить устройство**, укажите IP-адрес и ключ miio — строку из 32 шестнадцатеричных символов. Модель можно оставить пустой: программа определит её при подключении. Нажмите **Проверить подключение**, затем **Сохранить**.

Ключ можно получить через [Xiaomi-cloud-tokens-extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor) или `miiocli cloud`. Он сохраняется в локальном файле `%APPDATA%\MiMonitorLightTray\config.json`; не публикуйте этот файл вместе с диагностикой.

## Управление

- Щелчок по значку в трее открывает панель ламп с выключателями и ползунками яркости и температуры света. Нажмите `Esc` или щёлкните вне панели, чтобы закрыть её.
- Правая кнопка на значке открывает меню: настройки, виджет рабочего стола, язык, автозапуск Windows и проверка обновлений.
- В **Настройках → Изменить устройство** задаются горячие клавиши и отдельные правила: включение при запуске программы, выключение при выходе, реакция на сон монитора и сон или пробуждение компьютера.
- Для каждой лампы используйте отдельные сочетания клавиш. Например, `Ctrl+Alt+Up` и `Ctrl+Alt+Down` для яркости, `Ctrl+Alt+Right` и `Ctrl+Alt+Left` для температуры света. Правый щелчок по полю очищает сочетание.
- Виджет рабочего стола управляет первой лампой из списка. Его можно перемещать за заголовок и блокировать через правый щелчок.

Названия устройств, IP-адреса, ключи, модели и диагностические подробности сторонних библиотек сохраняют исходный текст. Переключение языка не изменяет настройки ламп. Старые файлы конфигурации поддерживаются; новое поле `language` принимает `auto`, `ru`, `en` или `zh`.

## Параметры запуска

Сначала завершите уже работающую копию программы через **Выход** в меню трея.

```powershell
.\MiMonitorLightTray.exe --language ru
.\MiMonitorLightTray.exe --setup
.\MiMonitorLightTray.exe --debug
```

`--language` выбирает язык при запуске: `auto`, `ru`, `en` или `zh`. Сам параметр не записывает конфигурацию; выбор через меню трея или сохранение настроек запоминает текущий язык. `--setup` открывает список устройств, `--debug` включает подробный журнал.

## Запуск, тесты и сборка из исходников

Нужен Python 3.9 или новее. В PowerShell:

```powershell
git clone https://github.com/awakaze/MiMonitorLightTray.git
cd MiMonitorLightTray
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[build,dev]"
.\.venv\Scripts\python.exe -m mi_monitor_light_tray --language ru
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\build_exe.py
```

Результат сборки — `dist\MiMonitorLightTray.exe`. Инструкции для разработчиков переводов находятся в [LOCALIZATION.md](LOCALIZATION.md), подробная информация об устройствах и протоколах — в [основном README](README.md).

## Если лампа недоступна

Проверьте питание, IP-адрес и общую локальную сеть. Протокол miio использует UDP-порт 54321. После повторного подключения лампы в Xiaomi Home ключ может измениться — импортируйте данные заново. Для отчёта об ошибке полезны модель и версия программы; IP-адреса, ключи и данные аккаунта публиковать не нужно.
