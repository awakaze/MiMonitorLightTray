# v1.5.3

## ✨ 开机补偿刷新 · 开机状态不再卡"离线"

v1.5.3 解决了普通开机（区别于休眠唤醒）后的一个体验问题：**开机时首次刷新若因网卡/扩展坞还未就绪而失败，程序此前不会自动重试，状态就一直停在"离线"，直到用户再次点开托盘窗口才重新连接**——给人的感觉就是"开机后查灯状态很慢 / 明明灯是好的却显示离线"。

## ✨ 新功能

### 开机补偿刷新（三轮重试）

仿照 v1.5.1 里"系统唤醒 → +0s / +3s / +8s 三轮刷新"的机制，把普通开机的刷新也改成同样的补偿轮次：

- **开机即对全部设备做三轮刷新**（t+0s / +3s / +8s），覆盖开机瞬间 WiFi / 扩展坞网卡晚就绪的平均 1~3s 延迟。
- 首轮失败不再"一锤定音"，后续轮次会把它刷回正常，首次打开托盘看到的就是实时而不是旧缓存。

### 开机自启开灯改为并行

- "开机自启开灯"原来按设备**串行**处理：一台设备的 UDP 超时会拖慢后面所有设备。
- 新版改为**每台设备独立线程并行**，且每一轮都会重试开灯——即使首轮网卡没就绪，等它可达后也会补上开灯，不再"失败一次就彻底放弃"。

## 🧹 其它

- **点击托盘窗口（Flyout）仍保持"先显示缓存 + 后台静默刷新"**，打开弹窗秒开，刷新完成后自动校正为最新状态；并行刷新保证一台卡住不阻塞其他设备。
